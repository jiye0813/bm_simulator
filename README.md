# 📊 BM 매출 예측 시뮬레이터

> 게임 외형 BM 담당자를 위한 판매 실적 기록 · 매출 예측 · 확률 분석 통합 툴

**[→ 라이브 데모 보기](https://jiye0813.github.io/bm_simulator/)**

---

## 만든 이유

아이템 스타일에 따라 매출 편차가 큰 외형 BM 을 기획할 때 가장 자주 맞닥뜨리는 질문은 세 가지입니다.

- **"이번 외형, 얼마나 팔릴까?"** — AU · BUR · ARPBU 기반 예측이 필요합니다.
- **"과거 유사 유형 상품 매출은 어떻게 됐지?"** — 히스토리 데이터와 나란히 비교해야 합니다.
- **"확률 구조가 매출에 어떤 영향을 주지?"** — 키 아이템 확률과 기대 비용을 수치로 봐야 합니다.

이 툴은 위 세 가지 질문을 한 화면에서 답할 수 있도록 설계되었습니다.

---

## 주요 기능

### 📁 판매 히스토리 — 실적 기록

과거 판매 데이터를 구조화하여 저장하고, 시뮬레이터의 기준 데이터로 활용합니다.

| 항목 | 설명 |
|------|------|
| 기본 정보 | 상품명 · 판매 시작일 · 종료일 · 채널 · 시즌 |
| 실적 지표 | 매출 · BU · ARPBU · AU · BUR (상호 자동 계산) |
| 확률 구성표 | 아이템명 · 확률(%) · 키 아이템 여부 — 행 직접 입력 또는 엑셀 임포트 |
| 일자별 매출 추이 | 날짜별 매출 수동 입력 또는 판매 기간 자동 채우기 — 입력 즉시 라인 차트 시각화 |
| 메모 | 콜라보 내용, 특이사항, 인사이트 자유 기재 |

#### 확률 구성표 엑셀 임포트
- **양식 다운로드** 버튼으로 기본 양식 (.xlsx) 다운로드
- 양식: `아이템명 / 확률(%)` 2열 구조
- 숫자(1.00) 또는 퍼센트 서식(1.00%) 모두 임포트 가능
- 임포트 후 키 아이템 여부는 UI에서 직접 체크

---

### 🔮 시뮬레이터 — 매출 예측

히스토리 데이터를 기준으로 다양한 변수를 조정해 예상 매출을 시뮬레이션합니다.

| 항목 | 설명 |
|------|------|
| 기준 지표 | AU · BUR · ARPBU · 판매 가격 · 기간 직접 입력 또는 히스토리에서 불러오기 |
| 변수 보정 | 시즌 이슈 (주년/명절/콜라보 등) · AU 보정 배율 · BUR 보정 슬라이더 |
| 확률형 구조 | 회당 가격 · 평균 구매 횟수 · 키 아이템 기대 획득 횟수 |
| 시나리오 비교 | 기본 / 낙관(+20%) / 보수(-20%) 3시나리오 동시 계산 |
| 일자별 예상 매출 추이 | 판매 기간 기반 초반 집중 패턴 곡선 — 기본/낙관/보수 3선 동시 표시 |
| 실적 오버레이 | 히스토리에 일자별 데이터가 있으면 실적선(분홍 점선)을 예측선과 함께 표시 |
| 과거 유사 판매 비교 | 시뮬레이션 결과와 히스토리 상위 5건 나란히 비교 |

---

### 📈 차트 인터랙션

- 모든 차트에 마우스 오버 툴팁 지원
- 데이터 입력 중 일자별 매출 입력 시 **실시간** 차트 갱신
- 시뮬레이터 수치 변경 시 일자별 예상 추이 차트 **즉시 갱신**

## 포트폴리오 관점에서

- **BM 기획 실무 경험 기반 설계** — 아이온 외형 BM 매출 200% 성과를 만든 기획 프로세스(데이터 진단 → 전략 수립 → 사후 분석)를 툴로 구현했습니다.
- **AU · BUR · ARPBU 지표 체계** — 실무에서 사용하는 게임 매출 지표를 그대로 적용해, 비개발 직군도 직관적으로 사용할 수 있습니다.
- **예측 → 기록 → 비교** 워크플로를 단일 툴에서 지원합니다.
- [의장 대시보드](https://jiye0813.github.io/mabinogi-dress/)와 함께, **분석(드레스룸) → 기획(시뮬레이터)** 워크플로를 구성합니다.
