# 📊 외형 BM 판매 시뮬레이터

> 과거 판매 기록을 기반으로 신규 외형 BM의 예상 매출을 시뮬레이션하는 기획 지원 툴

---

## 만든 이유

BM 기획 시 예상 성과를 추정할 때, 기존에는 매번 엑셀로 수동 계산하거나 감에 의존하는 경우가 많았습니다. 이 툴은 **과거 판매 기록(히스토리)을 체계적으로 관리**하고, 그 데이터를 기반으로 신규 상품의 예상 BU·매출·BUR을 시뮬레이션할 수 있도록 설계했습니다.

특히 확률형 아이템 구조에서 중요한 **키 아이템 등장 확률 및 기대 비용**을 함께 계산할 수 있어, 상품 가치 검증까지 지원합니다.

---

## 주요 기능

### 탭 1 — 판매 히스토리

과거 판매 기록을 등록·관리합니다.

**기록 항목**

| 항목 | 설명 |
|------|------|
| 상품명 / 판매 기간 / 채널 / 시즌 | 기본 판매 정보 |
| 최종 매출 | 해당 판매 회차의 실제 매출 |
| BU | 구매 유저 수 |
| ARPBU | 유저 1인당 평균 결제액 (매출/BU 자동 계산) |
| AU | 당시 활성 유저 수 |
| BUR | 구매 전환율 = BU/AU × 100% (자동 계산) |
| 확률 구성표 | 아이템명 / 카테고리 / 확률(%) / 키 아이템 여부 |
| 메모 | 콜라보, 특이사항, 인사이트 자유 기재 |

**자동 계산**
- BUR = BU ÷ AU × 100
- ARPBU = 매출 ÷ BU
- 키 아이템 합산 확률 및 기대 획득 횟수

**확률표 엑셀 임포트**
- `.xlsx` / `.xls` / `.csv` 파일 지원
- 컬럼 구조: `아이템명 / 카테고리 / 확률(%)` (1행 헤더 포함)
- JSON 내보내기 / 가져오기 지원

---

### 탭 2 — 매출 시뮬레이터

히스토리 데이터를 기반으로 신규 판매 예상 성과를 계산합니다.

**기준 데이터**
- 히스토리에서 원클릭으로 불러오기 (AU, BUR, ARPBU, 가격 자동 세팅)
- 직접 입력도 가능

**변수 보정**
- 시즌 이슈 선택 (주년 ×1.8 / 콜라보 ×2.0 / 연말 ×1.6 등) 또는 직접 입력
- AU 보정 배율 슬라이더
- BUR 보정 배율 슬라이더

**확률형 구조**
- 회당 가격 × 평균 구매 횟수 → ARPBU 자동 계산
- 키 아이템 기대 획득 횟수 → 1인 기대 비용 산출

**시나리오 비교**

| 시나리오 | AU 보정 |
|----------|---------|
| 기본 | ×1.0 |
| 낙관 | ×1.2 |
| 보수 | ×0.8 |

**과거 히스토리 비교**
- 시뮬레이션 예측값과 실제 과거 판매 결과를 나란히 비교
- 예측 대비 실적 차이(%) 자동 표시

## 포트폴리오 관점에서

이 툴은 두 가지를 동시에 증명합니다.

**BM 기획 사고방식** — 단순 매출 계산이 아니라, 실무에서 실제로 쓰는 지표(BU, BUR, ARPBU, AU)와 의사결정 변수(시즌, 확률형 구조, 키 아이템)를 모두 반영한 설계입니다.

**과거 데이터 기반 기획** — 히스토리 관리 → 기준값 추출 → 시뮬레이션의 흐름은 실제 BM 기획 프로세스와 동일합니다.

[마비노기 의장 대시보드](https://jiye0813.github.io/mabinogi-dress/)와 함께, **분석(드레스룸) → 기획(시뮬레이터)** 워크플로를 구성합니다.
